# world-memory-card

显示名「记忆卡」。

把一个目录里的 Markdown 按规则裁成一张卡，作为环境提示变量放进系统前缀。卡在每次交接重建前缀时重新生成，所以每个 session 开头看到的，都是那一刻磁盘上的样子。

写它的原因：文件里的要求常被跳过。把要它记住的部分放进前缀，比再写一条提醒可靠。

- **只读**：不改、不搬、不新建你目录里的文件，也不写盘。
- **不做模型调用**：纯字符串处理，毫秒级，没有 key，不联网。
- **只多三个变量**：`mc.meta` / `mc.card` / `mc.index`，没有工具、没有定时器。

## 它不做什么

- 不在 session 中途刷新。前缀在一个 session 里是固定的，文件改了要等下一次交接，或在控制台点「立即应用」。
- 不判断内容重要性。留哪一段由规则和字数上限决定，不由模型决定。
- 不删除、不压缩你自己的文件。去重和改写是你自己的事。

## 配置（`worlds.memory-card.*`）

| 键 | 默认 | 说明 |
|---|---|---|
| `enabled` | `true` | 装完就开。关掉就不再往前缀里放这张卡 |

其余设置都在 World 页的 **「设置」** 面板里，落盘到 `<data>/memory-card-settings.json`：

| 卡片 | 能改什么 |
|---|---|
| 第 1～5 条 | 文件、取法、取法的参数、字数上限、超了切哪头 |
| 总设置 | 目录、整张卡上限、最多列几个、列出未载入的文件、跳过的目录或文件 |

一条规则管一份文件，**文件留空就跳过那一条**。取法是下拉，不用再手写 `常驻.md|whole||2000` 这种一行五段的格式。

首次启动会把 `config.json` 里的旧规则槽和旧参数迁过来，之后以设置文件为准；`config.json` 里那几个旧字段不再读。

### 取法

仓库默认只填三份：

```
第 1 条  常驻.md                       整份装入        2000 字
第 2 条  partner/偏好与习惯.md          整份装入        2000 字
第 3 条  记忆.md                       到「## 按需」之前 + 后面的块目录   1600 字
第 4 条  留空
第 5 条  留空
```

流水、大事记、`games/*` 归 ledger，这里不用管。顺序就是优先级：总上限不够时，从最后一条开始整份丢。

| 取法 | 参数 | 取什么 |
|---|---|---|
| `whole` | 留空 | 整份，超上限截断；上限留空则不单独限制 |
| `marker` | 标题，如 `## 按需` | 从开头到该标题之前；找不到就整份载入并注明 |
| `marker+outline` | 标题 | 同上，再把该标题之后各块的块头与字数列出来；正文仍在磁盘上 |
| `newest` | 块数 | 按 `## ` 分块，取标题里日期最新的几块，保持文件里的先后 |
| `newest+pin` | `块数,标题` | 同 `newest`，再固定带上标题含该词的块（如 `1,待办`） |

`marker+outline` 是给「按需」那类章节用的：前面每轮都要看，后面动手才翻。卡上留一份目录，她知道有什么、要不要现在读：

```
## 按需（动手时才读，不进前缀）
- 环境和路径 752 字
- 教训 662 字
（这些块没上卡，用 read_file 查看 记忆.md。）
```

大纲不算在这一份的字数上限里：前面几节写得再长，也不会把目录挤掉。

日期从块标题里认：`## 11-05`、`## 2026-11` 都行。没有日期的块不会被 `newest` 选中；文件里出现过哪一年，就用那一年补全 `MM-DD`。

「超了切哪头」也是下拉：

| 值 | 含义 |
|---|---|
| `tail`（默认） | 断尾：留开头，丢掉结尾 |
| `head` | 截头：从整行开头起，留结尾；不为凑上限整块丢 |

日记式的文件（新的写在最后）用 `head`，最近的部分不会被切掉；稳定说明用默认的 `tail`。`head` 只按换行找起点，不从半句开始；截点落在某块中间时，正文开头会补一行「（前面已截断；这一段从「11-08（周日）」中间开始。）」。被整段切掉的块仍会进「未上卡的块」。`newest` 选块仍按日期取最新，方向只决定最后那次截断。

`newest` 和 `newest+pin` 只取几块，其余块不会出现。卡尾会列一份「未上卡的块」：没被取到的块，以及为字数上限整块丢掉的块，都带标题与字数；`mc.meta` 里也报个数。条数受 `listMax` 限制。整理记忆前按这份清单打开文件，不会因为卡上没写就漏掉。

路径相对 `folder`，不能是绝对路径，也不能用 `..` 跳出去。

### 卡片长什么样

```
### 记忆.md（11-07 11:16）

# 记忆

## 名字
...
（已截断：还有 940 字未载入，用 read_file 查看 记忆.md。）

### 未上卡的块

- 超近期.md：11-05（周四） 1123 字

这些块没进卡。整理记忆、或问到相关的事时，先打开对应文件读一遍；卡是交接时生成的，未必是此刻的样子。

### 未载入的文件

- 另一个文件.md：它自己的首行

问到相关的事，先打开对应文件再答。
```

### 模板

默认模板随扩展一起装好。装好后可以在控制台「提示词」页的 `worlds.memory-card.envPrompt` 里改，保存的版本会盖过默认的。

| 变量 | 内容 |
|---|---|
| `mc.meta` | 读取几份、多少字、几块未上卡、生成时间 |
| `mc.card` | 正文，每段带文件名与修改时间 |
| `mc.index` | 未载入文件的清单 |

正文里那三个占位符是模板的一部分，删了对应内容就不会出现在前缀里。

## 安装

在扩展页「手动安装 → 从 npm」里填 `world-memory-card`，装完重启进程，再在 World 总览里打开「记忆卡」——默认就是开的，规则去同一页的「设置」面板里选。

更新到新版本时，按扩展页提示点「重启进程」；如果控制台是单独开着的一页，**再刷新一次**（`Ctrl+R`）——页面清单（哪个 World 有哪些面板）只在开页时取一次，宿主重启不会让它重取。面板或样式看着还是旧的，就用 `Ctrl+Shift+R` 硬刷新：扩展的 `webui.js` / `webui.css` 按版本号地址缓存，普通刷新不会重新拉。更新不会动你的规则，它们在 `data/memory-card-settings.json` 里。

配置改完不需要重启，点「立即应用」或等下一次交接即可。
