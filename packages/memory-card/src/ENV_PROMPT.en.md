### How to use it

- What the card shows is what there is: a section marked as truncated is missing its remainder — read the file for it.
- A section that only lists block headings (with sizes) keeps their text on disk; read the file for the block you need.
- Files in the list are not on the card; open the one you need with `read_file`.
