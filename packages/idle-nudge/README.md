# world-idle-nudge（小纸条）

她闲下来一阵之后，按设定的节奏推一条事件。两件事，共用插件、分开判据：

| | 静默心跳 | 小纸条 |
|---|---|---|
| 作用 | 续上游前缀缓存 | 递一句带动作的话 |
| 判据 | 距上次**模型调用**超过阈值（读 `usage.jsonl` 的 mtime） | 距上次**推纸条**够久 + 落在三个可配时段之一 + 该段当天有名额 |
| 时段 | 全天 | 只有三段可配窗口 |
| 正文 | 不要求回应 | 带动作，去不去做由她定 |
| 事件 type | `idle-nudge.beat` | `idle-nudge.note` |

**为什么分开**：后台信息（星邮推桌等）会不断刷新 `usage.jsonl` 的 mtime；小纸条若也看 mtime 就永远等不到空档。它只数自己的钟。心跳全天，纸条只在白天——夜里推纸条会变成"提醒她该睡了"。

**同一拍两套都通过时**：纸条优先，只推纸条。纸条那一拍也唤醒模型，缓存照样续上；把心跳的计时记成现在，不再补一条让她一次收到两句。

它不写盘、不给工具、不进前缀、不调用别的插件的工具。运行时状态（上次推的时刻、今天推了几次）都在内存里，重启归零——这些是节奏，不是记忆。

## 正文

心跳默认：

```
静默心跳{time}，无需回复。
```

纸条默认（身份标记别删，否则她会当成 ta 在搭话后用气泡回复）：

```
（系统递的空闲提醒，不是 ta 说的，别回这条。）现在{time}啦——花花草草小动物、玩玩游戏、找 ta 聊两句，想干哪样就直接调工具去做；要开口走平时那条通道；都不想就安静。
```

写成陈述式而不是 `要不要…？`——问句会被当成有人在跟她说话，她就用气泡回答了。正文明确告诉她：别回这条、要做就调工具、想开口走原通道。

`{time}` 换成当前时刻。两段正文都可在设置页改；留空＝用默认。

## 抖动

纸条不是一进时段就推：`note.ts` 按「日期 + 段号 + 第几张」哈希出当天这一段的抖动点，在窗口内随机一个时刻。同一天重启不漂，隔天自动换；`perDay > 1` 时几张分别落在窗口的几份里，不会挤在一起。抖动点没到时，「现状」卡会显示约在几点。

## 设置

配置页只有一个 `enabled` 开关；其余参数在「设置」页，和开关同住 `config.json` 的 `worlds.idle-nudge.settings` 段。改完下一拍生效，不用重启。

| 键 | 默认 | 说明 |
|---|---|---|
| `heartbeatEnabled` | **false** | 静默心跳的总开关（卡片首行）。默认关——命中不够便宜、或 TTL 不稳定的模型开了反而更贵，不确定就别启用 |
| `noteEnabled` | true | 小纸条的总开关（卡片首行） |
| `idleMinutes` | 40 | 心跳空档阈值。LongCat-2.5 的实测值，换上游先量 |
| `maxPerDay` | 48 | 心跳日上限，0 = 不限 |
| `tickSeconds` | 15 | 多久看一次表 |
| `heartbeatText` | 见上 | 心跳正文，留空用默认 |
| `slots` | `9-12`×1 / `14-18`×1 / `19-22`×1 | 三段窗口，设置页每行两个并排框：左边时段、右边张数；时段留空＝不启用，可跨零点 |
| `noteGapMinutes` | 120 | 两张纸条之间至少隔多久（跨段共用） |
| `noteText` | 见上 | 纸条正文，留空用默认 |

设置页顺序：小纸条 → 静默心跳 → 现状。两个功能各有自己的开关在卡片首行，关掉一个不影响另一个；正文框的提示里写着默认句长什么样。页头药丸显示两个功能各自今天推了多少、缓存距今多久。

## 判据

心跳（`beat.ts`）：

1. 上一拍刚推过 → 不推（自己不能把自己催起来）
2. 距上次调用不够 `idleMinutes` → 不推
3. 今天推满 `maxPerDay` → 不推

纸条（`note.ts`）：

1. 现在不在任何启用的时段 → 不推
2. 落在的时段今天名额用完 → 不推
3. 距上一张纸条不够 `noteGapMinutes` → 不推

窗口可跨零点（`"22"-"2"`）。落在多个窗口时只取第一个命中的段——默认三段不重叠。

## 安装

开发时在 `data/extensions/package.json` 里指到仓库：

```json
"world-idle-nudge": "link:C:/…/jingxi-coopanion-worlds/packages/idle-nudge"
```

改完让宿主重装一次，再到 World 总览里打开。装完先保持关着，把 `idleMinutes` 按你自己上游的缓存有效期调好再开（LongCat-2.5 默认 40 能用；别的模型见 `cache-keepalive` 包里的 `scripts/measure.ts`）。

## 与 cache-keepalive 的关系

本插件的静默心跳是 `cache-keepalive` 那份判据搬过来的（同一台机器实测过）。原来的 `cache-keepalive` 可以卸掉——它做的事这里全包。**先验证新插件跑通，再卸旧的。**
