## 记忆板

下面这段是每次交接时从磁盘重新读出来的，不是你此刻写的，也不会在这个 session 中途刷新。每段开头是来源文件和它的修改时间；清单里的文件不在板上，问到时先打开再答。

### 怎么用

- 先看卡尾的「覆盖」：它写着覆盖到哪天、缺哪几天、有没有哪一天同时躺在两份文件里。缺了或重了，整理记忆时先把那一块补齐或挪走，再看别处。
- 标了「已截断」的段落，缺的部分用 `read_file` 读原文件，别凭印象补。
- 卡尾「未上卡的块」是这张卡没读到的部分：整理记忆时先打开它们，别只凭卡——卡是交接时生成的，可能已经隔了几小时。
- 清单里的文件不在板上。问到相关的事，先打开对应文件。
- 板上没有的事就是没有，别用「我记得」填空。

### 写记忆

往这几份文件里动字，都用工具，**不要用 `write_file` / `append_file` / `edit_file` 直接改**——文件末尾是「还挂着」，往末尾追加会把内容写进那一块里。

- 加一条 → `ml_add`。同类的事以前发生过，把那几个日期写进 `again`，它会带上「（again: …）」。
- 写「这一天的一句话」→ `ml_add(..., first=true)`，它插在这一块的最前面，不追加到末尾。每个日期块的第一行就是这一天的一句话，30 字以内，写这一天的主线（不是流水第一条，别以 `13:00` 这种时刻开头）；细节记在它下面。
- 改已有的一句 → `ml_edit(file, block, old, new)`。`old` 照抄，必须在这一块里只出现一次。要把一条改成两条，`new` 里带换行就行。文件头（第一个 `##` 之前那几行，不属于任何块）写 `block="文件头"`。
- 删一条 → `ml_delete(file, block, old)`。`old` 写这条里一小段就够，命中两条会拒绝。
- 淘汰一条（不是删）→ `ml_forget(file, block, old)`：从这份文件移出，整条归档进归档文件，**它不会再回来**。`大事记` 满了、要拿新的换掉旧的时候用这个；新的一条不如旧的，就直接 `ml_add(file="archive/大事记-归档.md")`，大事记一个字不动。

每条只写一件事，最多 600 字。写错不用猜：回执会附上这一块现有的前几条，或这份文件里有哪些块，照着改。三个工具写完都会重新解析核对，对不上就不写盘。

### 整理记忆时

1. 先跑 `ml_check`：看缺口、看有没有哪一天躺在两份文件里。
2. 把一整天搬到另一份文件，用 `ml_move(from, block, to)`。**不要用 `move_file` 按行搬**——行数算错一行，就会把下一天的开头一起切走。
3. 一次只做一件事，做完回报：搬了哪几块、各多少字、两个文件现在的块标题。
