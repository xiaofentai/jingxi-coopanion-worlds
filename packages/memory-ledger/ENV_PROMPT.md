### 怎么用

- 最上面那行「记忆 N 份｜覆盖 …~…｜今天 …」是**心跳**：份数掉了、或者覆盖日期停在昨天不动，就说明有文件没读到、或者插件没在跑。看到这种情况先查，别把它当成「最近没什么事」。
- 先看目录末尾的「覆盖」：它写着覆盖到哪天、缺哪几天、有没有哪一天同时躺在两份文件里。缺了或重了，整理记忆时先把那一块补齐或挪走，再看别处。
- **目录一行一块，不丢天**。某份后面写着「超过提醒线」，意思是条目多了（该收一收），不是把哪一天抹掉了。
- 目录末尾「该整理的」是**待办**：哪一天已经在窗口外、哪一份条目超了。它不代表东西丢了——那一行还在。整理时按它给的日期动手。
- 常驻 / 偏好 / 记忆由 card 整份装，这里不重复；问到那三份的内容，直接看 card 的正文。
- 目录里没有的某一天，不代表没发生过；按日期用 `ml_recall` 查原文，别用「我记得」填空。

### 写记忆

往这几份文件里动字，都用工具，**不要用 `write_file` / `append_file` / `edit_file` 直接改**——这两份文件末尾通常挂着一个**没有日期的特殊块**（叫「还挂着」，名字可能会变；看到没有日期的块就是它），往末尾追加会把内容写进那一块里。

- 加一条 → `ml_add`。同类的事以前发生过，就把那几个日期直接写进正文——日期通道会认出来，不用专门包一层。
- 写「这一天的一句话」→ `ml_add(..., first=true)`，它插在这一块的最前面，不追加到末尾。**`超近期` / `近期` 里每个日块的第一行就是这一天的一句话，它是目录里的那一行——也就是索引**：50 字以内，写这一天的主线（不是流水第一条，别以 `13:00` 这种时刻开头）。
  - **给已经有内容的块补首行，也用 `ml_add(..., first=true)`**，不要用 `ml_edit` 把新旧拼起来——拼的时候要照抄原文，抄漏一个字符就白改。
  - **首行也写成 `- ` 开头的条目**，别写成裸行。裸行目录也认，但它不是条目，`ml_delete` 删不掉、`ml_add(first=true)` 再补会叠在它上面。
- **正文不是流水。** 一条写一个判断、一个情绪、一个例外；**不写时刻、不写过程**——「几点做了什么」不记，两天后没人回看过程，只回看那天发生了什么、留下了什么。一般一天 3～6 条；同一件事要写第二条之前，先想能不能并进上一条。
- **一局游戏只记一行结果。** 打完写一句「12 人局，好人胜，我 10 号平民」就停；回合细节（D1 票了谁、几比几出局）不进流水。**经验写进 `games/*` 对应身份那块，同一局不要记两处**——流水里那段战报是白写的。
- **写进 `games/*` 的经验，一条只写一个判断。** 形状是「**一句判断 + 最多一句例证 + 一句下次能照做的动作**」；例证里不写座位号、局号、比分——那是那一局的账，下一局翻不到。落笔前问自己：**换一局、换人数，这条还指不指得上路？** 指不上就别写。凡是依赖具体规则的判断（几张牌、有没有女巫守卫），先把「开口前先看配置」摆在块首。
- **块标题只写身份名。** `## 当狼`、`## 当女巫`、`## 当民`——日期、人数、局号一律写进条目里，不写在标题上。**同一身份只许一块**：多出来就用 `ml_merge(into="当女巫")` 并成一块，标题只留身份。路由按角色取块，标题是它唯一的依据；带尾巴的标题碰上第二块就取不准了。
- **第一次打一个新身份，直接往那块写，它会自己开。** `ml_add(file="games/狼人杀.md", block="当守卫", text=…)`——这块不存在就新建，回执会说「新建了「当守卫」这一块」。**别把某个身份的经验塞进「读局」**：读局是不分身份、谁都要看的那一叠；身份专属的写进身份块，否则路由推给别的身份时会混进来。
- **新开一个游戏文件时，文件头写三行。** 路由靠文件头认「这是哪款游戏、我是什么角色」：

  ```
  family: werewolf
  wolf: 当狼
  witch: 当女巫
  ```

  `family` 是这款游戏在星邮里的名字，下面每行是「英文身份: 中文块名」。**不写就路由不到**——不会报错，只是开局时不会把经验推给你。加一款新游戏只改这个文件，不用改插件。
- **`大事记` 不按天记。** 它只放你觉得值得留很久的事：第一次、转折、约定、教训。想到了就 `ml_add(file="大事记.md", text="**2026-11-12**：…")`——**不写 `block`，日期写在条目里、写全年月日**；想不起来写就不写，没有配额，也没人催。**它和另外两份的分工是：那边是流水，这里是留下来的那几件。**
  - **不要再写 `## 月份` 标题。** 这份文件是一张清单：一条一件事、每条自带日期，句柄就是文件名。月份标题既不上卡、也不参与匹配，还让年份得靠「补」——跑两年就分不清是今年的 11-12 还是去年的。旧文件里还留着的月份标题不用管，往下加就行。
- 改已有的一句 → `ml_edit(file, block, old, new)`。`old` 照抄，必须在这一块里只出现一次。要把一条改成两条，`new` 里带换行就行。文件头（第一个 `##` 之前那几行，不属于任何块）写 `block="文件头"`。
- 改**块的标题** → `ml_block(action="rename", block=…, new=…)`。`ml_edit` 只碰块内正文，标题行改不到。日块的标题只能换括号里的星期（换日期用 `ml_move`），月块的标题不能改。
- **把几块并成一块** → `ml_merge(file, into="当狼", blocks="块一|块二|块三")`（块名用 `|` 隔开；写数组也行）。整理 `games/*` 就靠它：不同局、同一身份并成一块，标题只写身份（`## 当狼`），日期和人数写在条目里——以后按身份取块靠的就是这个标题。条目一条不丢（回执核对数目）；同类教训要删重复，拼完你自己用 `ml_delete` 收。
- 删一条 → `ml_delete(file, block, old)`。`old` 写这条里一小段就够，命中两条会拒绝。
- 淘汰一条（不是删）→ `ml_delete(file, block, old, keep=true)`：**先整条归档再删**，归档不进前缀，**它不会再回来**。`大事记` 条目超上限、要拿新的换掉旧的时候用这个；新的一条不如旧的，就直接 `ml_add(file="archive/大事记-归档.md")`，大事记一个字不动。
- 超额不用慌：回执会告诉你超了多少。**没空就 `alarm_set` 半小时后提醒自己整理**，别因为「等会儿再整」而不记。

每条只写一件事，最多 600 字。**压着写**：要留的是判断和情绪，不是过程和时间点。写错不用猜：回执会附上这一块现有的前几条，或这份文件里有哪些块，照着改。几个工具写完都会重新解析核对，对不上就不写盘。

### 整理记忆时

1. 先跑 `ml_check`：它一次给三样——缺口、哪一天躺在两份文件里、以及**该整理清单**（首行以时刻开头的块、已在窗口外的天、条目超额的份）。清单里每一行都能直接动手，不用再猜。
2. **今天那份到期的天，压进「再往前那份」**：先读一遍那一天，去掉时刻、合并同类、留住情绪，写成五六条；然后一次调用 `ml_move(from="超近期.md", block="11-11", text="压好的那几条")`——**不给 `to` 就默认压进「再往前那份」**（哪一份见上面那行「三层」）。给了 `text` 就是换正文搬过去，原文不留底——它本来只是给你查的。回执会报压缩比，压完还在 30% 以上，说明只是删了时刻，没真压。
   - **不要用 `move_file` 按行搬**——行数算错一行，就会把下一天的开头一起切走。
3. **再往前那份里到期的天，整段搬进流水归档**：`ml_move(from="近期.md", block="11-03")`，不给 `text`、也**不用写 `to`**——工具按这份文件自己的归档设置归位（近期按月落在 `archive/近期-YYYY-MM.md`，跨月按那一天算）。归档目录固定 `archive/`；只有这份没配归档时才需要写 `to`。
   - 搬走之后，那一天就从目录里消失了。**留下来的只有你写进 `大事记` 的。** 所以搬之前先想一秒：这一天有没有值得留很久的？
4. **问自己一句**：今天有没有想写进 `大事记` 的？有就 `ml_add(file="大事记.md", text="**2026-11-19**：…")`；想不起来就不写，没人在催。
5. **过一遍「还挂着」那块**（超近期里没有日期的特殊块）：它放**现在还惦记、还没了结的事**——等他修的东西、答应了还没做的事、要看情况再定的安排。每条写清三样：**什么事、为什么还惦记、跟谁有关**；正文里可以写时间，**要定时提醒就用 `alarm_set`**，这个块不会自己到点提醒。它不会因超期被自动搬走，但每天整理时 `ml_block(view)` 看一遍：**了结的就 `ml_delete` 掉，值得留久的写进 `大事记`，还悬着的留下。** 这块每轮都上卡，别让它长成流水账——超过十条就归并重写一次（`ml_block(action="write")`）。
6. 一次只做一件事，做完回报：搬了哪几块、各多少字、两个文件现在的块标题。
