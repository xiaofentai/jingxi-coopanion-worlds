### 怎么用

- 先看卡尾的「覆盖」：它写着覆盖到哪天、缺哪几天、有没有哪一天同时躺在两份文件里。缺了或重了，整理记忆时先把那一块补齐或挪走，再看别处。
- **卡片不截断任何内容**。某份后面写着「超过提醒线」，意思是它比设定的更长了（该收一收），东西没少，别以为缺了一块。
- 卡尾「该整理的」是**待办**：哪一天已经在窗口外、哪一份条目超了。它不代表东西丢了——目录一行一块全上卡，那一行还在。整理时按它给的日期动手。
- 卡尾「未上卡的块」是 `newest` 那种模式没读到的部分，整理时先打开它们。
- 清单里的文件不在板上。问到相关的事，先打开对应文件。
- 板上没有的事就是没有，别用「我记得」填空。

### 写记忆

往这几份文件里动字，都用工具，**不要用 `write_file` / `append_file` / `edit_file` 直接改**——文件末尾是「还挂着」，往末尾追加会把内容写进那一块里。

- 加一条 → `ml_add`。同类的事以前发生过，把那几个日期写进 `again`，它会带上「（again: …）」。
- 写「这一天的一句话」→ `ml_add(..., first=true)`，它插在这一块的最前面，不追加到末尾。**`超近期` / `近期` 里每个日块的第一行就是这一天的一句话，它是目录里的那一行——也就是索引**：40 字以内，写这一天的主线（不是流水第一条，别以 `13:00` 这种时刻开头），细节记在它下面。
  - **给已经有内容的块补首行，也用 `ml_add(..., first=true)`**，不要用 `ml_edit` 把新旧拼起来——拼的时候要照抄原文，抄漏一个字符就白改。
  - **首行也写成 `- ` 开头的条目**，别写成裸行。裸行目录也认，但它不是条目，`ml_delete` 删不掉、`ml_add(first=true)` 再补会叠在它上面。
- **`大事记` 不按天记。** 它只放你觉得值得留很久的事：第一次、转折、约定、教训。整理时想到了就 `ml_add(file="大事记.md", block="2026-11", text="**11-12**：…")`，按月聚、一行一件；想不起来写就不写，没有配额，也没人催。**它和另外两份的分工是：那边是流水，这里是留下来的那几件。**
- 改已有的一句 → `ml_edit(file, block, old, new)`。`old` 照抄，必须在这一块里只出现一次。要把一条改成两条，`new` 里带换行就行。文件头（第一个 `##` 之前那几行，不属于任何块）写 `block="文件头"`。
- 改**块的标题** → `ml_rename(file, block, new)`。`ml_edit` 只碰块内正文，标题行改不到，所以有这个工具。整理 `games/*` 时把标题统一成 `## 当狼 · 八人 · 11-05` 这种形状——以后按角色 / 人数取块就靠标题。日块的标题只能换括号里的星期（换日期用 `ml_move`），月块的标题不能改。
- 删一条 → `ml_delete(file, block, old)`。`old` 写这条里一小段就够，命中两条会拒绝。
- 淘汰一条（不是删）→ `ml_forget(file, block, old)`：从这份文件移出，整条归档进归档文件，**它不会再回来**。`大事记` 条目超上限、要拿新的换掉旧的时候用这个；新的一条不如旧的，就直接 `ml_add(file="archive/大事记-归档.md")`，大事记一个字不动。
- 超额不用慌：回执会告诉你超了多少。**没空就 `alarm_set` 半小时后提醒自己整理**，别因为「等会儿再整」而不记。

每条只写一件事，最多 600 字。**压着写**：要留的是情绪和细节，不是流水账。写错不用猜：回执会附上这一块现有的前几条，或这份文件里有哪些块，照着改。几个工具写完都会重新解析核对，对不上就不写盘。

### 整理记忆时

1. 先跑 `ml_check`：它一次给三样——缺口、哪一天躺在两份文件里、以及**该整理清单**（首行以时刻开头的块、已在窗口外的天、条目超额的份）。清单里每一行都能直接动手，不用再猜。
2. **窗口外的天，整块搬到 `archive/`**：`ml_move(from, block, to="archive/近期-流水.md")`。**不要用 `move_file` 按行搬**——行数算错一行，就会把下一天的开头一起切走。
   - 搬走之后，那一天就从目录里消失了。**留下来的只有你写进 `大事记` 的。** 所以搬之前先想一秒：这一天有没有值得留很久的？有就先 `ml_add` 一条进大事记，没有就直接搬——不写也没关系，它还在归档里。
3. 一次只做一件事，做完回报：搬了哪几块、各多少字、两个文件现在的块标题。
